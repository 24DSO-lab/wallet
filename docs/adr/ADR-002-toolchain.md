# ADR-002: Инструменты сборки

14 ноября 2026 · Dev 1 · статус: предложено, до подтверждения `wails doctor` на Windows

## Решение

| Инструмент | Версия | Основание |
| --- | --- | --- |
| Go | 1.27.4 | Последний выпуск в списке go.dev/dl на 14 ноября 2026 (рядом 1.26.11). Подтверждает Dev 1 |
| Wails | v2.17.0 | Последний стабильный v2 (на странице релизов помечен «Latest»). v3 остаётся бета-версией (v3.0.0-beta.34, pre-release), решение D1 |
| Node.js | 22.x | Версия, на которой проверялась сборка фронтенда в окружении Dev 1 (22.23.4). Текущий LTS на момент старта не сверялся, закрепить в CI после проверки |

Переход на Wails v3 только отдельным ADR.

## Что не проверено

- `wails doctor` не запускался: у окружения, где писался PR #0, нет Wails CLI и нет доступа к `proxy.golang.org`, поэтому зависимость `github.com/wailsapp/wails/v2` не скачана, `go.sum` не создан.
- `go build ./...` с `main.go` и `wails build` на Windows не прогонялись.
- Директива `go 1.27.4` в `go.mod` не проверялась компилятором 1.27: локальные проверки шли на Go 1.24 с директивой `go 1.24.0`.

Закрыть до слияния: на машине с сетью выполнить `go get github.com/wailsapp/wails/v2@v2.17.0 && go mod tidy`, закоммитить `go.sum`, прогнать `wails doctor` и `wails build`, внести фактические версии в таблицу.
