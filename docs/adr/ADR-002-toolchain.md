# ADR-002: Инструменты сборки

14 ноября 2026 · Dev 1 · статус: принято, версии подтверждены `wails doctor`

## Решение

| Инструмент | Версия | Источник |
| --- | --- | --- |
| Go | 1.27.3 локально, `go.mod` требует 1.27.4 (см. ниже) | `wails doctor` на Windows 10 Pro 22H2; список go.dev/dl |
| Wails | v2.17.0 | `wails doctor`; последний стабильный v2, v3 остаётся бета-версией (решение D1) |
| Node.js | 24.13.1 (npm 11.8.0) | `wails doctor` |
| WebView2 | 157.0.4341.46 | `wails doctor` |

Переход на Wails v3 только отдельным ADR.

## Что подтверждено

`wails doctor` на Windows 10 Pro (build 19045), amd64: «Your system is ready for Wails development». `go.sum` создан, зависимость Wails v2.17.0 зафиксирована в `go.mod`.

## Открыто

- **Расхождение версий Go.** В `go.mod` стоит `go 1.27.4`, на машине разработчика 1.27.3. При `GOTOOLCHAIN=auto` Go скачает 1.27.4 сам, при `GOTOOLCHAIN=local` сборка остановится. Решить: обновить Go до 1.27.4 или понизить директиву до `go 1.27.3`. Dev 1 подтверждает выбор для всей команды, CI берёт версию из `go.mod`.
- **Node.** В окружении Dev 1 проверялась 22.x, на машине сборки 24.13.1. Закрепить в CI одну мажорную версию, когда появится `package.json`.
- **`wails build`** на Windows: результат не передан, пока не зафиксирован.
