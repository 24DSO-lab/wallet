# Ручное тестирование на тестовых сетях

Только test-профиль: Bitcoin testnet, Ethereum Sepolia, TRON Nile. Реальные суммы не использовать (mainnet заблокирован гейтами ADR-001).

## Подготовка

1. Собрать: `wails build -clean -platform windows/amd64` (или `node scripts/wails-dev.mjs` для разработки).
2. Перед сборкой после обновления `go.mod` выполнить `go mod vendor`.
3. Задать ключи провайдеров (см. README): `ETHERSCAN_API_KEY` (или сохранить ключ в Настройках), при необходимости `ALCHEMY_API_KEY`, `TRONGRID_API_KEY`.
4. Взять тестовые монеты из кранов: BTC testnet, Sepolia ETH, Nile TRX; USDC (Sepolia) и USDT (Nile) по необходимости.

## Сценарии

| № | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| 1 | Первый запуск, создание кошелька (12 слов) | Фраза показана один раз, проверка слов по позициям, кошелёк создан, пароль не короче 12 символов |
| 2 | Блокировка и разблокировка | Без пароля разделы недоступны, неверный пароль даёт ошибку без утечки деталей |
| 3 | Получение BTC/ETH/TRX | Адрес и QR показаны, «Проверить адрес» по паролю даёт «адрес подтверждён» |
| 4 | Баланс и история после пополнения из крана | Баланс совпадает с обозревателем, транзакция в истории |
| 5 | Отправка с неверным адресом / нулевой суммой / лишними знаками | Понятная ошибка до экрана подтверждения |
| 6 | Отправка BTC, ETH, USDC, USDT | Проверка, подтверждение паролем, txid виден в обозревателе |
| 7 | Повторная отправка при неподтверждённой предыдущей | Блокируется с пояснением |
| 8 | BTC RBF: «Ускорить» на неподтверждённой транзакции | Создана замена, старая получает статус «заменена» |
| 9 | Резервная копия и восстановление на чистом профиле | После восстановления подсказка проверить адреса, адреса совпадают |
| 10 | Импорт той же фразы с passphrase и без | Адреса различаются, сверка первых адресов показана |
| 11 | Смена пароля, переименование, показ фразы, удаление | Каждое действие требует пароль, удаление ещё и точное имя |
| 12 | Автоблокировка по таймеру | Сессия блокируется через заданное время |
| 13 | Отключить сеть и обновить балансы | Ошибка по активу, остальные данные сохранены |

## Что записать

Для гейтов 2, 3 и 5 (`docs/gates/`): адрес, txid, статус и время проверки в обозревателе. Найденные ошибки — с шагами воспроизведения и без паролей и фраз.
